# Open letter to all parties

Cancel should be as easy as subscribe.

This repository holds a single-page open letter to every federal, provincial and territorial political party in Canada. The page is `index.html`. It loads no third-party scripts, fonts, or analytics.

Public comments belong on the [Issues page](https://github.com/jasincanada/open-letter-subscription-fairness/issues). Do not post account numbers, payment details, addresses, or private correspondence.

The letter is signed by a concerned citizen in British Columbia. The page itself does not name a person, city, or company.
